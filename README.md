# Callegold — Tienda virtual

Tienda virtual estática construida con HTML5, CSS3 y JavaScript. Incluye 32 referencias del catálogo original, fotografías, categorías, buscador, carrito de selección y consultas por WhatsApp.

## Publicar con GitHub Pages
En GitHub abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**. El archivo `index.html` se encuentra en la raíz del repositorio.

## Archivos
- `index.html`: página inicial y catálogo.
- `css/`: diseño premium y adaptable.
- `js/products.js`: referencias y descripciones.
- `js/cart.js`: carrito local.
- `js/main.js`: buscador, filtros y enlace de WhatsApp.
- `assets/products/`: fotografías del catálogo.
